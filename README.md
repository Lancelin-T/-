# 田宇航的数据可视化前端作品
基于 Streamlit 构建的铝电解槽工艺曲线可视化与数据标注系统，用于展示电解槽的槽电压、工艺参数和阳极电流曲线，同时提供数据标签与反馈收集功能。

## 数据来源

**本项目所有数据均为自动生成的模拟数据**，用于作品展示目的。

数据存储于本地 MySQL 数据库 `db_for_portfolio` 中，包含以下核心数据表：

| 表名 | 说明 | 数据粒度 |
|------|------|----------|
| `dwd_daily_para` | 工艺日报数据 | 天级（每日一条） |
| `dwd_realtime_2t` | 实时采集数据 | 2分钟级 |

### 关键数据字段

- **k_device**: 槽号（设备号），如 `1301`~`1334`
- **k_ts**: 时间戳
- **槽电压/设定电压**: `pot_voltage`, `set_voltage`, `voltage_upper_limit`, `voltage_lower_limit`
- **阳极升降状态**: `andoe_move_state_zh`（自动/手动 阳极升/降）
- **特殊事件**: `special_state_zh`（出铝、换极、效应、抬母线、纯手动）
- **下料状态**: `feeding_state_zh`（氟盐下料、小下料、大下料AEB）
- **下料间隔**: `set_feeding_interval`, `actual_feeding_interval`
- **针振/摆动**: `fluctuation`, `waving`
- **系列电流**: `series_current`
- **工艺参数**: `temperature`(槽温), `molecular_ratio`(分子比), `aluminum_level`(铝水平), `electrolyte_level`(电解质水平), `fe_content`(Fe含量), `si_content`(Si含量), `feeding_weight`(下料量), `aluminum_output_weight`(出铝量) 等
- **斜率**: `slope`, `cumulative_voltage_slope`

数据可通过离线 CSV 文件导入（标签工具模块），CSV 文件要求前三列依次为 `k_device`, `k_ts`, `k_model`。

## 各页面说明

### 页面1：槽电压曲线（`pot_voltage`）

- **路径**: `pot_voltage/index.py`
- **功能**: 选择工区、槽号、日期，点击"查询"后展示该槽单日的槽电压 Plotly 交互式曲线图。
- **图表内容**:
  - 槽电压曲线（蓝实线）与设定电压（红虚线）、电压上下限（灰虚线）
  - 阳极升/降事件散点标注（绿色=自动，红色=手动）
  - 换极/出铝/效应/抬母线/纯手动事件文字标注
  - 下料间隔曲线（映射到电压Y轴范围）
  - 针振/摆动曲线
  - 系列电流曲线（右侧Y轴，单位 kA）
  - 斜率/累斜/定斜曲线
  - 左上角浮层显示工艺参数摘要（槽龄、槽温、分子比、铝水平等）
- **交互方式**: 支持缩放、悬停查看数值、自由拖拽浏览。

### 页面2：工艺曲线 V1（`pot_process`）

- **路径**: `pot_process/index.py`
- **功能**: 选择工区、槽号、日期范围，点击"查询"后使用 Matplotlib 生成静态工艺参数多子图，以 PNG 图片形式展示。
- **图表内容**: 12 个子图（单列排列），每个子图为散点+折线+数值标签：
  1. 电压（设定电压 + 工作电压）
  2. 氟盐下料量（设定 + 实际）
  3. 槽温
  4. 出铝量（计划 + 实际）
  5. 分子比
  6. 下料量
  7. 噪声（针振 + 摆动）
  8. 基准下料间隔
  9. 铝水平
  10. 电解质水平
  11. Fe含量
  12. Si含量
- **输出**: 图片自动保存至 `./fig/铝一1分厂/工艺曲线/默认图片.png`

### 页面3：工艺曲线 V2（`pot_process_plotly`）

- **路径**: `pot_process_plotly/index.py`
- **功能**: 与 V1 相同的工艺参数数据，但使用 Plotly 交互式渲染。
- **增强特性**（相比 V1）:
  - 支持缩放、悬停查看详细数值
  - 每个子图右上角显示该指标时段内的**均值**
  - 左上角显示图例色块
  - 更好的响应式体验

### 页面4：标签工具（`mark_tool`）

详见下方"标签工具详细说明"。

## 标签工具详细说明

标签工具是本系统的核心功能模块，用于对电解槽生产数据记录进行人工标注和反馈。适用于专家/分析师查看槽控曲线后，对数据记录进行分类标记并给出文字反馈的场景。

### 作用

1. **数据加载**: 支持上传 CSV 离线数据文件，自动解析并渲染为分页交互表格。
2. **曲线查看**: 每行记录对应一次槽控事件，点击可查看三类曲线图（槽电压、工艺参数、阳极电流），图表中会自动高亮标注该条记录对应的时间位置。
3. **标注与反馈**: 每行提供下拉标记框（预定义分类）和自由文本反馈输入。
4. **结果导出**: 一键下载包含原始数据 + 标记 + 反馈列的完整 CSV 文件。

### 使用方法

#### 第一步：上传数据文件（可使用文件夹里的示例数据“(工区反馈)原始记录_NB_20260203.csv”）

1. 在左侧边栏选择数据源为"离线文件"。
2. 点击"Browse files"上传 CSV 文件。
3. **文件格式要求**：前三列必须严格按照 `k_device`（槽号）、`k_ts`（时间，如 `2026-01-15 08:30:00`）、`k_model`（类型/模型标识）顺序排列。后续列可包含任意额外字段。
4. 上传成功后，数据表格自动渲染显示，每页 10 条记录。

#### 第二步：查看曲线图

1. 在表格中找到需要分析的数据行。
2. 点击该行的 **📊 按钮**，弹出"槽控曲线详情"对话框。
3. 对话框包含三个标签页：
   - **📈 槽控曲线**: 展示该条记录时间点前后 12 小时的槽电压 Plotly 交互曲线。记录时间点前后各 10 分钟区域会以 **红色半透明矩形** 高亮标注，并附上类型标签。
   - **📊 工艺曲线**: 展示该条记录前 30 天至后 6 天的工艺参数 Plotly 交互曲线（12 个子图）。
   - **⚡ 阳极电流**: 展示该槽当天的阳极电流分布静态图（A1~A14, B1~B14 共 28 根导杆的电流值）。
4. 图表生成的 HTML 文件会缓存至 `标签工具/html_charts/` 目录，重复查看同一记录时直接读取缓存，提升加载速度。
5. 点击"关闭图表"退出弹窗。

#### 第三步：标记与反馈

1. **标记下拉框**: 每行记录提供预定义分类选项：
   - `(空)` — 未标注
   - `人工调整有误` — 人工干预判断错误
   - `人工调整正确` — 人工干预判断正确
   - `调整待研究` — 调整效果待进一步研究
   - `已处理` — 该问题已处理完毕
2. **反馈文本框**: 输入自由格式的文字反馈意见。
3. 修改标记或反馈后，点击该行的 **"提交"按钮** 保存（提交按钮仅作确认提示，数据实时保存在 session 中）。

#### 第四步：导出结果

1. 完成所有标注后，点击页面右上角的 **"完成反馈并下载反馈记录"** 按钮。
2. 或者点击最下方生成的下载按钮，下载 `标注数据_YYYYMMDD_HHMMSS.csv` 文件。
3. 导出文件包含：原始 CSV 的所有列 + `标记` 列 + `反馈` 列。

### 呈现效果

- 表格采用分页显示（每页 10 条），支持上一页/下一页导航。
- 额外列（CSV 中除前三列之外的所有列）通过表格顶部的 checkbox 控制是否显示。
- 弹窗采用大尺寸（95vw 宽度），确保曲线图有足够的展示空间。
- 图表使用 Plotly 引擎渲染，支持鼠标缩放、平移、悬停查看数值。

### 输出效果

导出的 CSV 文件示例结构：

```
k_device,k_ts,k_model,...,标记,反馈
1302,2026-01-15 08:30:00,type_A,...,人工调整有误,出铝后电压回升过快需关注
1305,2026-01-15 09:45:00,type_B,...,,正常
1308,2026-01-15 11:20:00,type_C,...,调整待研究,效应后针振异常
```

- 未标注的行，`标记` 列为空字符串。
- 文件编码为 UTF-8-BOM，兼容 Excel 直接打开。

## 运行方式

```bash
# 安装依赖
pip install streamlit pandas pymysql loguru matplotlib plotly

# 启动服务（在作品集文件目录下执行）
streamlit run entrypoint.py
```

服务默认运行在 `http://localhost:8501`。

## 技术栈

| 技术 | 用途 |
|------|------|
| **Streamlit** | Web 应用框架，页面渲染与交互组件 |
| **Plotly** | 交互式曲线图（槽电压、工艺曲线 V2） |
| **Matplotlib** | 静态图表（阳极电流图、工艺曲线 V1） |
| **Pandas** | 数据处理与 CSV 读写 |
| **PyMySQL** | MySQL 数据库连接 |
| **Loguru** | 日志记录 |

## 注意事项

1. 数据库连接配置在 `common/mysql_handler.py` 中，需要本地 MySQL 服务运行且包含 `db_for_portfolio` 数据库。
2. 标签工具页面依赖 `streamlit.dialog`，需要 Streamlit 版本 >= 1.38。
3. 工艺曲线 V1 生成的图片路径为 `./fig/铝一1分厂/工艺曲线/默认图片.png`，每次查询会覆盖此文件。
4. 阳极电流图缓存于 `./images/阳极电流图/{槽号}/` 目录下，首次生成耗时较长。
5. 标签工具的图表 HTML 缓存位于 `标签工具/html_charts/`，如果数据更新需要手动删除缓存文件以重新生成。
